Put instrumental `.mp3`, `.wav`, or `.ogg` files here. Use music you own or have
permission to use. Short beats are looped to fit the vocals; long beats are trimmed.

For an original, locally synthesized demo beat, run:

```sh
python tools/make_demo_beat.py
```

No downloads or paid services are needed for this beat. The script writes
`sloth-hop.wav` here and will not overwrite an existing file.
